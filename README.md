# 🌸 FloraSense AI

### Smart Flower Intelligence Using Machine Learning

FloraSense AI is a machine learning application that predicts Iris flower species using the K-Nearest Neighbors (KNN) algorithm.

## Features
- Flower species prediction
- KNN machine learning model
- Adjustable K value
- Model accuracy evaluation
- Confusion matrix
- Classification report
- Prediction history
- CSV download

## Technologies
- Python
- Streamlit
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Joblib

## Dataset
Iris Flower Dataset from Scikit-learn.

## How to Run

Install dependencies:

pip install -r requirements.txt

Run application:

streamlit run app.py
